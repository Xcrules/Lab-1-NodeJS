# Lab 1 - Node.js

## 1. CLI Calculator
Run:
`node calculator.js 20 + 10`

## 2. Custom Module
Run:
`node moduleDemo.js`

## 3. HTTP Server
Run:
`node server.js`

Then open:
- http://localhost:3000/
- http://localhost:3000/about
- http://localhost:3000/contact

## 4. File Manager
Run:
`node fileManager.js`

## 5. Random Dice Generator
Run:
`node dice.js`
